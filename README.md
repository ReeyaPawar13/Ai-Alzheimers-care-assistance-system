# CareMate: Alzheimer's Patient Assistance & Care Management System

## Project Description

CareMate is a professional full-stack application designed to assist Alzheimer's patients, caregivers, and doctors in managing daily care, medicines, schedules, tasks, appointments, memory aids, and communication.

## Features

- Three user roles: Patient, Caregiver, Doctor with role-based dashboards and access
- Authentication with email and phone (password hashing and JWT)
- Patient dashboard with medicines, schedules, tasks, SOS alerts, memory book
- Caregiver dashboard to manage patient care, medicines, schedules, alerts
- Doctor dashboard for patient monitoring, appointments, reports, chat
- AI assistant with fallback mode for Alzheimer's-friendly support
- Mind games, exercise suggestions, period tracker (placeholders and functional basic UIs)
- Real-time updates via polling (or minimal Socket.IO integration for chat planned)
- Responsive and accessible UI with Tailwind CSS and Bootstrap
- Demo mode with seeded sample users and data for demonstration without external API keys

## Technology Stack

- Frontend: React.js, Vite, Tailwind CSS, Bootstrap 5, Axios, React Router, Lucide Icons
- Backend: Node.js, Express.js, MongoDB, Mongoose, JWT, bcrypt
- AI Assistant: Google Gemini API integration or fallback local responses
